# Alexkkkkk — Open Source Projects

## Give disk images a safer way to be explored.

**MountFile** is an open-source desktop tool for browsing and extracting files from raw disk images and NAND/eMMC dumps. It can inspect MBR/GPT partition tables and supports bounded file and folder operations in FAT32 image files.

The goal is simple: make working with disk images more approachable while keeping changes inside the image file—not writing them back to the physical device.
